Not stated in the briefs: connector and total heights, power draw, USB output current budget, throttling behaviour. These remain \textbf{unverified}.

\paragraph{Assessment.}
\begin{itemize}
  \item \textbf{Compute Modules:} rejected. They need a carrier board, which conflicts with using off-the-shelf parts and adds cost.
  \item \textbf{Zero 2 W:} the single micro-USB port must serve the drive (adapter or hub needed), Wi-Fi is 2.4 GHz only, and 512 MB of RAM is tight for SMB, web upload, email fetch and slideshow together. It has no DSI. It remains a fallback only if a prototype memory test passes.
  \item \textbf{Pi 4 B:} full-size USB ports for the drive, dual-band Wi-Fi, up to 8 GB RAM, and a smaller 3 A supply than the Pi 5. Operating range 0--50\,\textdegree C is fine for indoor use.
  \item \textbf{Pi 5:} fastest, but it asks for a 5 V/5 A supply, which makes the shared power supply larger and warmer, and the extra speed is not needed for a photo slideshow.
\end{itemize}

\textbf{Recommendation (pending owner approval):} Raspberry Pi 4 Model B, 4 GB. The RAM size is my judgment for headroom and is not a measured requirement. Re-check against R-MEC-1 once heights are known.

Sources: Botland (10.1DP-CAPLCD), waveshare.com (Touch-A), Waveshare wiki (LCD (C)), raspberrypi.com and Adafruit (Touch Display 2), RobotShop (LCD (E)), Elecrow wiki.

\paragraph{Assessment.}
\begin{itemize}
  \item \textbf{Elecrow:} rejected. Its listed viewing angle is 80\textdegree{} and brightness is a hardware key only, so it cannot meet R-FTR-4.
  \item \textbf{Touch Display 2:} rejected for now. It works only with the Pi 5 or a Compute Module, which excludes the recommended Pi 4.
  \item \textbf{LCD (E):} lowest resolution (1024$\times$600), no stated backlight control, highest price. Rejected.
  \item \textbf{DSI panels (Touch-A, LCD (C)):} flat ribbon and software backlight, but they need Pi-specific cables and a \texttt{config.txt} overlay, and the Touch-A is portrait-native (800$\times$1280) so landscape needs rotation.
  \item \textbf{10.1DP-CAPLCD:} works with any Pi over HDMI and USB, lists driver-free touch and software backlight control, and is 1280$\times$800 landscape. It also gives the widest choice if the Pi changes.
\end{itemize}

\textbf{Recommendation (pending owner approval):} Waveshare 10.1DP-CAPLCD. To verify on the bench: touch works without drivers on Raspberry Pi OS, backlight changes over DDC/CI, and the real thickness and power draw (the 5 V, 4 W figure is a seller number).
