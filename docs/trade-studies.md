# Trade Studies

Every rating, pinout and dimension used here must come from a datasheet in `docs/datasheets/` (local only) and be cited. Unverified values are marked **unverified**.

## 1. Raspberry Pi model
Drives: R-CMP-1, R-MEC-1, R-NET-1, R-UPL-*.
Candidates: Zero 2 W, 4, 5 (TBD). Compare depth, RAM, USB, idle power.

## 2. Display (10" IPS, touch)
Drives: R-DSP-1..3, R-FTR-4, R-MEC-1.
Candidates: TBD. Check panel thickness, touch interface, backlight control, input (HDMI, DSI), supply voltage.

## 3. Storage
Drives: R-STO-1, R-MEC-1.
Candidates: TBD. 2.5" SSD, M.2 NVMe in USB enclosure, and so on. Check height and bus-powered current draw.

## 4. Sensors
Drives: R-FTR-3, R-FTR-4.
Candidates: TBD PIR module, TBD ambient light sensor (I2C).

## 5. Power supply
Drives: R-PWR-1..5, R-CST-1.
Candidates: TBD. Universal input 100–240 VAC, NBR 14136 plug or detachable cord, INMETRO listing, output sized from the power budget plus 20%.

## 6. Enclosure
Drives: R-MEC-1..4.
Candidates: TBD store-bought frame. Check inner depth and opening size against the panel.
