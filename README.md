# pictureFrame

A slim DIY digital picture frame built from off-the-shelf parts around a Raspberry Pi.

- 10" IPS touchscreen in a store-bought frame with a 3D-printed rear shell, ≤ 25 mm deep
- Photos stored on an external USB drive
- Upload over Wi-Fi by SMB share, web page or email
- Screen schedule, motion wake and auto-brightness
- Powered from Brazilian mains (universal-input supply, NBR 14136 plug)

**Status:** requirements and trade studies. No parts chosen yet.

See [docs/design-notes.md](docs/design-notes.md) for requirements and decisions, and [docs/trade-studies.md](docs/trade-studies.md) for the open part selections.

Started from [hw-project-template](https://github.com/ZacharyManzali/hw-project-template).
